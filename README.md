# miaitec.github.io

The MIAITEC website, served by GitHub Pages at https://miaitec.com (see `CNAME`).

- `index.html`: home page
- `deadlock-traffic/`: Deadlock Traffic support page (`index.html`) and privacy policy (`privacy.html`),
  linked from the App Store listing. The originals live in the game's repository under `site/`.
- `air-monitor/`: Air Monitor (iPhone app for the MIAITEC Air Quality Monitor) support page
  (`index.html`) and privacy policy (`privacy.html`), linked from the App Store listing.
  App source: github.com/shikilee/Air-Quality-Monitoring-Sensor (`ios/AirMonitor`).
